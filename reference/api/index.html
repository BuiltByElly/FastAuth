    API reference

    Manually maintained surface of the public modules. Anything not listed here is internal.

    Entry points (fastauth, fastauth.core)

    • SessionAuth(adapter, db_session_dependency, user_model, session_model, ...) — .router, .current_user, password hooks, config, ctx
    • JWTAuth(adapter, db_session_dependency, user_model, refresh_model, ...) — plus .purge_expired_refresh_tokens(session), on_token_reuse_detected
    • OIDCAuth(adapter, db_session_dependency, user_model, oauth_account_model, strategy, session_model?, refresh_model?, ...) — .on_after_oidc_login, .current_user, default prefix /auth/oidc
    • OAuth2Auth(...) — same shape as OIDCAuth; .on_after_oauth2_login; default prefix /auth/oauth2
    • FastAuth — shared base; not usable directly (registers no routes)

    All take config: FastAuthConfig, rate_limiter: RateLimiter | None, tags, and prefix.

    Config (fastauth.config)

    FastAuthConfig, SessionConfig, CookieConfig, PasswordConfig, JWTConfig, RateLimitConfig, OIDCConfig, OIDCProviderConfig, OAuth2Config, OAuth2ProviderConfig. Full field reference: Config.

    Adapters (fastauth.adapters, fastauth.adapters.sqlalchemy, fastauth.adapters.rate_limit)

    • Adapter — subclass for a custom ORM (flush, never commit). RateLimiterAdapter — check(key, window, max_requests) -> bool.
    • SQLAlchemySessionAdapter, SQLAlchemyJWTAdapter; mixins FastAuthUserMixin, FastAuthSessionMixin, FastAuthRefreshTokenMixin, FastAuthRateLimitMixin, FastAuthPasswordResetTokensMixin, FastAuthOAuthAccountMixin.
    • InMemoryRateLimiter, SQLAlchemyRateLimiter, RedisRateLimiterAdapter.
    • Exceptions: EmailAlreadyRegistered.

    Hooks (fastauth.hooks)

    HookAbort(status_code, detail); events LoginFailure, PasswordResetRequested, PasswordChanged. Holder classes live in fastauth.hooks.{signup,login,logout,refresh,password,oauth}. Full contract: Hooks.

    Providers & types (fastauth.oauth, fastauth.types)

    • oauth.oidc.OIDCProvider — get_authorize_url(redirect_uri, state), fetch_user_info(code, redirect_uri) -> OAuthUserInfo
    • oauth.oauth2.OAuth2Provider — same authorize shape; fetch_user_info(...) -> OAuth2LoginResult
    • types.OAuthUserInfo(provider, provider_user_id, email, email_verified, name, avatar_url, others?), types.OAuth2LoginResult(user_info, access_token, refresh_token?, expires_at?)

    Misc

    • fastauth.protocols — UserProtocol, SessionProtocol, RefreshTokenProtocol, RateLimitProtocol, PasswordResetTokenProtocol, OAuthAccountProtocol, ensure_model_compliance(...)
    • fastauth.schemas — TokenResponse, build_signup_schema/login/user_response/password_reset_token_schema
    • fastauth.security — hash_password, verify_password, OAuthStateManager
    • fastauth.dependencies.rate_limiter — RateLimiter(adapter?, db_session_dependency?, rate_limit_model?, rate_limit_config?, redis_client?), .limit(window?, max_requests?), .limit_for(path)
